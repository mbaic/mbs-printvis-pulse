# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use [private vulnerability reporting](https://github.com/mbaic/mbs-printvis-pulse/security/advisories/new) on this repository instead. Include the affected file, the steps to reproduce, and the impact.

This is a demo project and is provided as is. Reports are handled on a best-effort basis.

## Scope

The app is read-only against PrintVis and bundles its chart add-in locally, with no external scripts. See the security note in the [README](README.md#security-note-external-components-in-add-ins).
